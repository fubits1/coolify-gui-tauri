Tab order rationale

  • Overview = default landing
  • Env behind a click — values masked, click-to-reveal
  • Compose read-only (no editing v1)
  • Logs lazy-load on tab activate
  • Images badge in tab shows stale count

Resource-type adaptations

  • Database: no Compose tab, Logs tab maps to db engine logs
  • Application (non-compose): Compose tab → "Dockerfile" or "Build config"
  • Service: Compose tab is primary editable view (v2)
